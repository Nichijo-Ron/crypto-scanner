# ชุดสแกนเหรียญอัตโนมัติ (GitHub + Telegram)

สแกนเหรียญตามรายชื่อที่คุณเลือก **ทุกชั่วโมง** ด้วยเงื่อนไข ATR Trailing Stop (ceyhun) + MA line + HAMA Candles (NSDT)
ทำได้ทั้งฝั่ง **Long และ Short พร้อมกัน** เลือก timeframe **1h / 4h / 1D** ได้ แล้วส่งผลเข้า **Telegram** ที่มือถือ

- ทำงานบนเซิร์ฟเวอร์ของ GitHub ไม่ต้องเปิดคอมและไม่ต้องติดตั้งโปรแกรมอะไรในเครื่อง
- แจ้งเฉพาะเหรียญที่ **เพิ่งเข้าเงื่อนไข** (ค่าเริ่มต้น) จะไม่ส่งซ้ำทุกชั่วโมง
- แก้ว่าจะสแกนอะไรได้เองที่ไฟล์ `config.json`
- ผลเป็นเพียงตัวกรองเหรียญ ไม่ใช่คำแนะนำการลงทุน ควรเปิดดูชาร์ตประกอบก่อนตัดสินใจเสมอ

> ชื่อเมนูของ GitHub และ Telegram อาจต่างจากที่เขียนไว้เล็กน้อยตามเวอร์ชัน ให้ดูตามความหมายเป็นหลัก

---

## ขั้นที่ 1: สร้างบอท Telegram (ทำครั้งเดียว)

1. เปิด Telegram ค้นหา **@BotFather** (เลือกอันที่มีเครื่องหมายถูกสีฟ้า)
2. พิมพ์ `/newbot` แล้วตอบชื่อบอทกับ username (ต้องลงท้ายด้วย `bot`)
3. BotFather จะส่ง **token** มาให้ หน้าตาประมาณ `123456789:AAExxxxxxxxxxxxxxxx` คัดลอกเก็บไว้ **ห้ามส่งให้ใครหรือโพสต์ที่ไหน** (ใครมี token ก็ควบคุมบอทได้)
4. ค้นหาบอทที่เพิ่งสร้าง กด **Start** แล้วพิมพ์ข้อความอะไรก็ได้ 1 ข้อความ
5. หา **chat id**: เปิดเบราว์เซอร์ไปที่ลิงก์นี้ (แทน `TOKEN` ด้วย token ของคุณ ไม่ต้องมีเครื่องหมาย < >)
   `https://api.telegram.org/botTOKEN/getUpdates`
   ในหน้าที่ขึ้นมาให้หาข้อความ `"chat":{"id":` ตามด้วยตัวเลข ตัวเลขนั้นคือ chat id
   (ถ้าขึ้น `"result":[]` แปลว่ายังไม่มีข้อความ ให้ส่งข้อความหาบอทอีกครั้งแล้วรีเฟรช)

เก็บ token กับ chat id ไว้ใช้ในขั้นที่ 3

**อยากให้เด้งบนจอคอมด้วย:** ติดตั้ง Telegram Desktop (หรือเปิด Telegram Web) แล้วล็อกอินบัญชีเดียวกัน ข้อความจากบอทจะเด้งป๊อปอัปบนคอมให้เอง (ถ้าอยากให้เด้งแม้ไม่ได้เปิดเว็บแอปสแกน ใช้วิธีนี้ได้เลย)

---

## ขั้นที่ 2: สร้างที่เก็บไฟล์บน GitHub (ทำครั้งเดียว)

1. สมัคร/เข้าสู่ระบบที่ **github.com**
2. กด **New repository** ตั้งชื่ออะไรก็ได้ เช่น `crypto-scanner`
   - เลือก **Public** เพื่อให้ใช้ GitHub Actions ฟรีแน่นอน (คนอื่นจะเห็นโค้ดและรายชื่อเหรียญใน `config.json` แต่ **มองไม่เห็นรหัส Telegram** เพราะเก็บแยกในขั้นที่ 3)
   - เลือก **Private** ก็ได้ถ้าไม่อยากให้ใครเห็น แต่จะใช้โควตาฟรีของบัญชี ให้ตรวจที่หน้า Settings → Billing ว่าพอไหม
3. กด **Create repository** ในหน้าถัดไปกดลิงก์ **uploading an existing file**
4. ลากไฟล์ 3 ไฟล์นี้ลงไป: `scan.mjs`, `config.json`, `README.md` แล้วกด **Commit changes**
5. สร้างไฟล์ตั้งเวลา: กด **Add file → Create new file**
   - ช่องชื่อไฟล์พิมพ์ว่า `.github/workflows/scan.yml` (พิมพ์ `/` แล้วระบบจะสร้างโฟลเดอร์ให้เอง)
   - เปิดไฟล์ `scan.yml` ที่ได้รับ คัดลอกเนื้อหาทั้งหมดมาวาง แล้วกด **Commit changes**

---

## ขั้นที่ 3: ใส่รหัส Telegram แบบลับ

ในหน้า repository ไปที่ **Settings → Secrets and variables → Actions → New repository secret** แล้วสร้าง 2 รายการ

| Name (พิมพ์ตามนี้เป๊ะ) | Secret (ค่าที่วาง) |
|---|---|
| `TELEGRAM_BOT_TOKEN` | token จากขั้นที่ 1 ข้อ 3 |
| `TELEGRAM_CHAT_ID` | chat id จากขั้นที่ 1 ข้อ 5 |

---

## ขั้นที่ 4: ทดสอบ

1. เปิดแท็บ **Actions** (ถ้าขึ้นให้กดยืนยันเปิดใช้ workflows ให้กดอนุญาต)
2. เลือก workflow ชื่อ **scan** ทางซ้าย → กด **Run workflow**
3. ติ๊ก **ส่งข้อความทดสอบเข้า Telegram** และ **ส่งรายการเหรียญที่เข้าเงื่อนไขตอนนี้ทั้งหมด** แล้วกด Run workflow สีเขียว
4. รอประมาณ 1 นาที ควรได้ข้อความทดสอบและรายการเหรียญใน Telegram
   ถ้าไม่ได้ ให้กดเข้าไปดูรอบที่รัน (วงกลมสีเหลือง/เขียว/แดง) แล้วเปิดขั้นตอน **Scan** เพื่ออ่านข้อความ error

จากนั้นระบบจะรันเองทุกชั่วโมงที่นาทีที่ 5 (เช่น 07:05, 08:05 น. เวลาไทย) หลังแท่ง 1h ปิด GitHub อาจเริ่มช้าไปบ้างช่วงที่ระบบโหลดสูง

---

## แก้ว่าจะสแกนอะไร (`config.json`)

เปิดไฟล์ `config.json` บน GitHub กดไอคอนดินสอเพื่อแก้ แล้วกด **Commit changes** รอบถัดไปจะใช้ค่าใหม่ทันที
ถ้าพิมพ์ผิดรูปแบบ ระบบจะส่งข้อความเตือนเข้า Telegram บอกว่าผิดตรงไหน

| ค่า | ความหมาย |
|---|---|
| `name` | ชื่อชุดสแกน (ห้ามซ้ำกัน) |
| `enabled` | `true` เปิด / `false` พักชุดนี้ไว้ |
| `exchange` | `binance`, `bybit`, `okx` หรือ `bitget` |
| `sides` | `["long"]`, `["short"]` หรือ `["long", "short"]` (สองฝั่งพร้อมกัน) |
| `tfs` | `["1h"]`, `["4h"]`, `["1d"]` หรือหลายอัน เช่น `["1h", "4h"]` ถ้าหลายอัน เหรียญต้องเข้าเงื่อนไขครบทุก TF |
| `coins` | รายชื่อเหรียญ คั่นด้วยเว้นวรรคหรือคอมมา เช่น `"BTC ETH SOL"` |
| `hama_min_step` | ความเข้มสี HAMA ขั้นต่ำ 1–5 (ค่าเริ่มต้น 3) |
| `min_volume` | วอลุ่ม 24 ชม. ขั้นต่ำเป็น USDT (0 = ไม่กรอง) |
| `min_range` | ช่วงราคาเฉลี่ยต่อแท่งขั้นต่ำเป็น % ที่ 1h (0 = ไม่กรอง) |
| `exclude_tokenized_stocks` | `true` เพื่อตัดหุ้น/ETF โทเคนที่ชื่อขึ้นต้นด้วย R |
| `max_coins` | จำนวนเหรียญสูงสุดต่อชุด |
| `notify` (ระดับบนสุด) | `"new"` แจ้งเฉพาะเหรียญใหม่ (แนะนำ) / `"all"` แจ้งรายการทั้งหมดทุกรอบที่มีเหรียญ |
| `timezone` | เขตเวลาที่ใช้แสดงในข้อความ (ค่าเริ่มต้น `Asia/Bangkok`) |

**เพิ่มชุดสแกนหลายแบบ:** คัดลอกก้อน `{ ... }` ของชุดเดิมในลิสต์ `scans` ไปวางต่อท้าย (คั่นด้วยคอมมา) แล้วเปลี่ยน `name` กับค่าอื่นๆ
เช่น ชุดหนึ่งสแกน `1h` ทั้งสองฝั่ง อีกชุดสแกน `["4h","1d"]` เฉพาะ Long

**แท่งที่ใช้ตรวจ:** แท่งที่ปิดแล้วล่าสุดของแต่ละ TF เสมอ ชุดที่เลือก `4h` หรือ `1d` จะแจ้งเมื่อเข้าเงื่อนไข (ตอนแท่งปิด) แล้วไม่แจ้งซ้ำ แม้ระบบจะตรวจทุกชั่วโมง

## ข้อควรรู้ / แก้ปัญหา

- **ข้อความเตือน HTTP 451 / 403 / fetch failed:** exchange อาจบล็อกเซิร์ฟเวอร์ของ GitHub ซึ่งอยู่ต่างประเทศ (บางเว็บบล็อกไอพีสหรัฐฯ) ให้เปลี่ยน `exchange` ใน `config.json` แล้วรัน Run workflow ทดสอบอีกครั้ง
- **หยุดแจ้งเตือนไปเฉยๆ:** GitHub จะปิดงานตั้งเวลาของ repository สาธารณะถ้าไม่มีกิจกรรมนาน 60 วัน ชุดนี้บันทึกไฟล์ `.keepalive` เองเมื่อเงียบเกิน 40 วันเพื่อกันไว้ (ยังไม่ได้ทดสอบบน GitHub จริง) ถ้าหยุดไปจริงให้เข้าแท็บ Actions แล้วกด Enable workflow
- **เวลาไม่ตรงเป๊ะ:** GitHub อาจเริ่มรอบสแกนช้าไปหลายนาทีในช่วงที่ระบบโหลดสูง บอทจะใช้แท่งที่ปิดแล้วล่าสุดเสมอ ผลจึงไม่เพี้ยน
- **รอบแรกข้อความยาว:** รอบแรกทุกเหรียญที่เข้าเงื่อนไขจะถือเป็น "ใหม่" หลังจากนั้นจะแจ้งเฉพาะที่เปลี่ยนไป
- **เหรียญที่ไม่มีบน exchange / ถูกกรอง / ดึงข้อมูลไม่ได้** จะถูกบอกไว้ท้ายข้อความ
- **ไฟล์ `state.json`** ระบบสร้างและอัปเดตเอง (ใช้จำว่าแจ้งอะไรไปแล้ว) ไม่ต้องแก้ ถ้าลบทิ้งรอบถัดไปจะแจ้งทุกเหรียญเป็นของใหม่อีกครั้ง
- **หยุดทั้งหมดชั่วคราว:** แท็บ Actions → เลือก **scan** → เมนูสามจุด → **Disable workflow**
- **อย่าแชร์ token** ถ้าหลุด ให้ไปที่ @BotFather พิมพ์ `/revoke` เพื่อออก token ใหม่ แล้วอัปเดตค่าใน Secrets
- ข้อมูลมาจากตลาด Spot การ Short จริงต้องเทรดฟิวเจอร์สหรือมาร์จิน ซึ่งมีความเสี่ยงสูงและไม่ได้มีทุกเหรียญ
